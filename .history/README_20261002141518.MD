# 📝 To-Do List App

A simple and interactive **To-Do List App** built using **HTML, CSS, and JavaScript**.  
The app allows users to manage their daily tasks, track their progress, and store tasks using **Local Storage**, so the tasks remain available even after refreshing the page.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit pending tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📊 Track completed tasks with a progress bar
- 🔢 Display completed tasks / total tasks
- 💾 Save tasks using Local Storage
- 🔄 Automatically restore saved tasks after refreshing
- 🎉 Confetti animation when all tasks are completed
- 🖼️ Empty-state image when there are no tasks
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Structure of the application

## ⚙️ How It Works

### Add a Task
Enter a task in the input field and click the **+** button or press **Enter**.

### Complete a Task
Click the checkbox next to a task. The task will be marked as completed and the progress bar will update automatically.

### Edit a Task
Click the **edit icon** on a pending task. The task text will be placed back into the input field so it can be modified and added again.

### Delete a Task
Click the **trash icon** to remove a task.

### Local Storage
Tasks are converted into JSON and stored in the browser's Local Storage. When the application is opened again, the saved tasks are loaded automatically.

## 📊 Progress Tracking

The application calculates the percentage of completed tasks:

```text
Completed Tasks / Total Tasks × 100
```

The progress bar and task counter update whenever a task is added, completed, edited, or deleted.

## 🎉 Completion Effect

When all available tasks are completed, a confetti animation is triggered to provide visual feedback.
